# Observatory — прототип

Витрина главного экрана мультиязычной платформы интерактивных гид-экскурсий.
Статическая вёрстка без сборки: `index.html`, токены и стили в `styles/`, ассеты в `assets/`.

Тема состоит из двух независимых осей, которые переключаются атрибутами на `<html>`:
`data-concept` (шрифты и формы) и `data-palette` (только цвет). Переключатель
в углу экрана — демонстрационный, не часть продукта.

Подробности системы — в `CLAUDE.md`.

# Map generator

Собирает реальную карту (настоящие улицы) и красит её под палитру места — Duomo, Cosmos, Rome и т.д. Без API-ключа.

## Установка (один раз)
```bash
pip install pillow numpy
```

## Запуск
```bash
python make_map.py                        # берёт настройки из блока CONFIG в файле
python make_map.py --palette duomo        # быстро сменить палитру
python make_map.py --lat 41.9028 --lon 12.4964 --zoom 15 --palette terracotta --out rome.png
```
Готовый PNG перетаскиваешь в Figma (или скинь мне — залью image-fill'ом в нужный фрейм).

## Что где крутить (блок CONFIG вверху файла)
| Параметр | Что делает |
|---|---|
| `center` | центр карты `(широта, долгота)` |
| `zoom` | 14 обзорно · 15–16 улицы · 17 крупно |
| `size` | размер PNG в px (бери ×2 от фрейма — под ретину) |
| `palette` | `duomo`, `night`, `cosmos`, `santorini`, `terracotta`, `krem` |
| `route` | список точек `(lat, lon)` — линия маршрута; пусто `[]` = только карта |
| `draw_pins` | `False`, если пины хочешь ставить слоями в Figma поверх карты |

## Добавить свою палитру
В словаре `PALETTES` добавь строку. Три цвета берёшь прямо из наших токенов:
```python
"my_city": {"base": "light", "bg": (255,255,255), "road": (200,196,190), "route": (19,18,17)},
```
- `base`: `dark` для тёмных палитр, `light` для светлых (выбирает тёмный/светлый баземап).
- `bg` = фон карты (токен `color/bg`), `road` = улицы (между `bg` и `text`), `route` = акцент маршрута (`color/accent`).

## Важно
- Тайлы — Carto + OpenStreetMap. Для прототипа ок; на макете подпиши **© OpenStreetMap © CARTO** (требование лицензии). Для продакшена/нагрузки — свой аккаунт Carto или Mapbox.
- Координаты точек сейчас примерные (Брера). Точные возьмёшь, кликнув место в Google/Apple Maps → «скопировать координаты».
- Если пины нужны интерактивными (превью по тапу) — ставь `draw_pins=False` и рисуй их слоями в Figma поверх карты-картинки.

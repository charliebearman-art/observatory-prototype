# Observatory — прототип

Мультиязычная платформа интерактивных гид-экскурсий по городам.
Слоган: **Explore. Observe. Understand.**
Источник правды по дизайну — Figma «Showcase» (`NESk9YjJiyTbstAl1uW3Yt`). Этот репозиторий — витрина для заказчика, **не** второе место, где ведётся дизайн.

---

## 1. Главное правило: две независимые оси темы

Тема состоит из **двух ортогональных осей**, которые переключаются атрибутами на `<html>`:

```html
<html data-concept="b" data-palette="cosmos">
```

| Ось | Что задаёт | Значения |
|---|---|---|
| `data-concept` | шрифты, скругления, интерлиньяж | `a` (Архивный), `b` (Светлый), `c` (Кинематографичный) |
| `data-palette` | **только цвет** — идентичность места | `duomo`, `santorini`, `krem`, `terracotta`, `night`, `cosmos` |

Смысл: концепция — это характер продукта, палитра — характер **места**. Гид по Риму окрашен иначе, чем по Комо, но остаётся тем же продуктом. Никогда не смешивай оси: цвет не задаётся в блоке концепции, шрифт — в блоке палитры.

Все значения — в `styles/tokens.css`, выгружены из переменных Figma. **Не хардкодь цвета, размеры, скругления и отступы — только `var(--token)`.** Если нужного токена нет, это сигнал обсудить систему, а не написать литерал.

---

## 2. Отступы кратны 4

Только `--space-1…--space-8` (4, 8, 12, 16, 24, 32, 48). Значений вроде 10, 14, 18, 30 в системе нет.

---

## 3. Правило вложенных скруглений

**Внешний радиус = внутренний радиус + отступ.**

Элемент, вложенный в контейнер с отступом 4, берёт `--radius-inner-4`, а не тот же радиус, что контейнер. Иначе углы не концентричны и выглядят криво (особенно заметно в концептах A и C).

```css
.chip        { border-radius: var(--radius-button); padding: var(--space-1); }
.chip__photo { border-radius: var(--radius-inner-4); }
```

Если появится вложенность с отступом 8 — заводим `--radius-inner-8` по той же формуле, а не подбираем на глаз.

Радиусы по смыслу: `--radius-card` (карточки), `--radius-button` (кнопки, чипы, бейджи — контрольный радиус), `--radius-input` (поля).

---

## 4. Текст поверх изображений

Фон-фотография непредсказуема, поэтому у неё **свои статичные токены**, которые не зависят ни от концепции, ни от палитры:

- `--on-media` — заголовки, цена, иконки (белый)
- `--on-media-muted` — вторичный текст (белый 72%)
- `--on-media-border` — обводки поверх фото (белый 30%)
- `--glass` — полупрозрачная подложка чипов/бейджей
- `--scrim` — затемнение под текстом

Правило: **белый текст + scrim-градиент под ним**, а не «подобрать цвет под фотографию». Иначе на светлом кадре текст пропадает. Контраст заголовка держим ≥ 4.5:1.

Никогда не используй `--color-text` поверх фото — он тёмный в светлых палитрах и светлый в тёмных, то есть непредсказуем.

---

## 5. Типографика

Размеры едины для всех концепций, интерлиньяж и гарнитура — от концепции.

| Роль | Размер | Переменные |
|---|---|---|
| Display | 48 | `--size-display` / `--lh-display` |
| H1 / H2 / H3 | 40 / 32 / 24 | `--size-h1` … `--lh-h3` |
| Title | 20 | `--size-title` / `--lh-title` |
| Body | 16 | `--size-body` / `--lh-body` |
| Caption / Label | 12 | `--size-caption` / `--lh-caption` |

Три гарнитуры на концепцию:
- `--font-display` — заголовки
- `--font-text` — текст для чтения
- `--font-ui` — интерфейсная хрома: кнопки, чипы, навигация

Кнопки используют `--font-ui`, а не `--font-text`. Это разные роли.

Шрифты грузятся с Google Fonts: Cormorant Garamond, Jost, Golos Text, Manrope, EB Garamond.

---

## 6. Иерархия кнопок

1. **Primary** — заливка `--color-accent`, текст `--color-on-accent`. Один главный призыв на экран.
2. **Secondary** — обводка 1.5 `--color-accent`, без заливки.
3. **IconButton** — квадрат 40/36, варианты Ghost / Outline / Filled. Иконка **всегда 24px**, меняется только контейнер.
4. **TextButton** — без рамки, только текст (+ опциональная иконка), для третичных действий.

Размеры: Large (текст 16) и Compact (текст 12, высота 36).
Состояния у всех: Default / Hover (`--color-accent-hover` или `--color-accent-subtle`) / Focus (кольцо на accent) / Disabled (opacity 0.4).

---

## 7. Иконки

`assets/icons.svg` — спрайт, 24×24, обводка 1.5, `currentColor`.

```html
<svg class="icon"><use href="assets/icons.svg#i-search"></use></svg>
```

Размер иконки не масштабируется от размера контейнера — меняются паддинги.

---

## 8. Контент и голос

Интерфейс и контент — **на английском**.

- Заголовок гайда = конкретное место/угол + обещание истории («The Quarter Behind the Galleries»), а не список достопримечательностей.
- Тизер = глагол действия + деталь, которую заметишь. 8–12 слов, одна строка карточки.
- Блоки главной: hero → What is Observatory? (Explore / Observe / Understand) → Popular in {City} → Beyond {City} → footer.
- Город — это **фильтр каталога**, отдельных страниц городов нет. «+24 more» открывает шит выбора города.

---

## 9. Чего не делать

- Не хардкодить цвет/размер/радиус/отступ мимо токенов.
- Не смешивать оси: цвет только в палитре, форма и шрифт только в концепции.
- Не ставить текст на фото без scrim.
- Не делать вложенные скругления равными внешним.
- Не заводить новый компонент, если задача решается вариантом существующего.
- Не менять раскладку «как удобнее в коде» — расхождение с Figma дороже, чем кажется. Если раскладка не сходится, это повод спросить.

---

## 10. Структура

```
prototype/
  index.html            — экран + переключатель концепта и палитры
  styles/tokens.css     — токены (выгрузка из Figma, правится только пересборкой)
  styles/base.css       — сброс, типографика, компоненты
  assets/icons.svg      — спрайт иконок
```

Картинки-обложки генерируются по промптам в едином грейде: приглушённый golden-hour, мягкий гаусс в нижнюю половину, зона под текст. Милан — прохладный крем, Рим — тёплая охра, Комо — холодная лазурь.
